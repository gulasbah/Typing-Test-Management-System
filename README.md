# Typing Test Management System

A desktop-based typing assessment application developed in Python using PySide6.

The system is designed to evaluate typing speed, accuracy, correct and incorrect words, and overall typing performance. It also generates a professional result report after the completion of a typing test.

## Features

- Typing speed calculation
- Accuracy calculation
- Correct and incorrect word tracking
- Timer-based typing tests
- Live performance results
- Progress tracking
- Automatic test completion
- Professional performance report generation
- User-friendly desktop interface
- SQLite-based result storage

## Technologies Used

- Python
- PySide6
- Qt
- SQLite
- QPrinter
- QPrintPreviewDialog

## Project Structure

- `main.py` – Application entry point
- `dashboard.py` – Main dashboard and interface
- `typing_test.py` – Typing test logic and performance calculations
- `database.py` – Database operations and result storage
- `assets/` – Images and application resources

## Purpose

The project was developed to provide a structured desktop environment for conducting typing tests and automatically calculating performance metrics such as typing speed and accuracy.

It also demonstrates practical experience in desktop application development, GUI design, database integration, performance calculation, and automated report generation.
